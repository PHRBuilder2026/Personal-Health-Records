The Name Behind Model Railroad Record Keeper

The Name Behind Model Railroad Record Keeper

If you installed the Mac version a while back, you may have noticed it sitting in your Applications folder under a different name: Track Runner. That was the app's original name, and the story of why it changed is short, mildly annoying, and — as of version 2.5 — finally finished.

Track Runner came first

Track Runner was the working name from the start, and a search of the App Store before submitting turned up nothing using it. That turned out not to be the whole picture. Once the app was submitted, the name came back as already reserved. Reserved names don't necessarily show up in a customer search — you find out when you file the paperwork.

A new name that says what it does

Rather than argue about a name, the app got one that describes the job: Model Railroad Record Keeper. On the iPad this barely registered. The label under the icon on your home screen is set separately from the store name, so the icon stayed put and nothing moved.

The Mac took longer to catch up

A Mac app carries its name in more than one place. The menu bar and the About box were updated first, so the app introduced itself correctly the moment you opened it. But Finder, Spotlight, Launchpad and the Dock read a different name — the one baked into the app file itself — and that one was still Track Runner. The result was an app that looked properly named while running and wrong everywhere you'd go looking for it.

A Mac customer wrote in about exactly that, which is how it finally got fixed. Version 2.5 renames the app file, so it now reads Model Railroad Record Keeper in Finder, Spotlight, Launchpad and the Dock.

One thing to check after you update

Because the app file itself was renamed, the new copy can land beside the old one instead of replacing it. If you end up with both, drag the old Track Runner to the trash. Your railroad data is stored separately and isn't touched either way.
